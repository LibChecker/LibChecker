## 2.5.5

- 支持了在线统计项，现在可以在图表页面添加、移除和排序统计内容
- 在应用详情页中增加了「检测在线规则」，可以查看当前应用是否符合已添加的在线统计规则
- 为部分已适配规则（Flutter 和 Jetpack）的库增加了 SDK 版本和附加信息检测，现在在规则详情页可能可以看到具体的版本信息
- 在库引用统计中新增了矩形树图模式，可以按引用数量查看库的分布，并通过双指缩放查看局部内容
- 在 Kotlin 图表中增加了按版本统计的详细模式
- 增强了混淆应用的 Kotlin 使用检测，并改进了 Kotlin 构建版本的识别
- 新增了 R8 构建信息检测，在支持的应用中，可以在 AGP 详情对话框中查看检测到的 R8 版本及 Full、Compatibility 模式信息（灵感来自GitHub@vvb2060）
- 支持了识别 APK Signature Scheme v3.2 签名方案
- 将原先的 Compose Multiplatform 检测调整为 Compose Multiplatform Resources 检测，避免一些情况下的误判问题
- 支持了检测应用声明的 AppFunctions，并在详情页面查看函数信息
- 在 Android 16 以上已为 Android MCP 预备好，新增了 AppFunctions 接口，支持兼容的调用方查询和分析应用、查找库引用以及查询和对比快照
- 新增了最近访问记录，可以通过长按导航栏中的应用和统计入口快速访问，并支持固定应用和库引用快捷项
- 在快照时间节点选择页面增加了更新热力图，可以查看快照保存日期，并按日期查看记录到的应用更新
- 重新设计了快照对比详情页面，增加了「差异强调」选项，并保留了切换至旧式卡片布局的选项
- 从此版本开始保存的快照会额外记录 DEX 信息和资源体积，支持对比 DEX 类数量、文件体积和内容变化，以及资源体积变化
- 现在支持将超长的快照文字报告作为文本文件分享
- 新增了「纯黑主题」和「悬浮导航」选项，并将外观相关选项整合至独立的设置页面
- 在 Android 13 以上新增了「模糊设计」界面选项
- 现在支持在应用详情页长按自适应图标查看前景和背景图层，并分别复制图层或完整图标
- 在权限长按菜单中增加了「提供者引用统计」，可以查看使用该权限的内容提供者
- 在 Xposed 模块详情中增加了自动热重载声明的展示，并优化了作用域应用列表的显示效果
- 重新设计了 FOSS 版本和 CI 版本的应用内更新流程，支持在应用内下载并请求安装更新
- 在设置页面增加了 GitHub Token 选项，适用于高频查看部分规则 SDK 的最近更新时间等场景
- 优化了启动、应用列表、应用详情、图表、库引用统计和快照处理的性能
- 改善了 APK、APKS、XAPK 和 ZIP64 压缩包的解析兼容性，修复了部分原生库展示和引用统计不完整的问题
- 改善了搜索和列表状态的恢复、底部弹窗的滚动衔接，以及无障碍体验
- 更新了一些 UI 设计、多语言翻译和依赖
- 更新了内置规则库版本
